#  E-Commerce Sales Analysis Dashboard – Power BI

## Project Overview

This project is an **E-Commerce Sales Analysis Dashboard** developed using **Microsoft Power BI** to analyze sales performance, customer trends, product performance, and payment methods.

The dashboard transforms raw e-commerce data into an interactive and easy-to-understand business intelligence report, helping users identify sales trends and key business insights.

## Objectives

* Analyze overall e-commerce sales performance
* Track total sales and total orders
* Monitor customer performance
* Analyze Average Order Value (AOV)
* Identify top-performing product categories
* Identify the Top 10 products based on sales
* Analyze sales distribution by payment mode
* Compare sales performance across years
* Analyze monthly sales and order trends
* Provide interactive filtering using Year and State

##  Dashboard Features

### Key Performance Indicators (KPIs)

* **Total Orders**
* **Total Sales**
* **Total Customers**
* **Average Order Value (AOV)**

### Visualizations

**Sales Trend Analysis** – Monthly sales performance
**Sales by Category** – Comparison of sales across product categories
**Top 10 Products by Sales** – Identifies the highest-selling products
***Monthly Sales KPI** – Tracks monthly sales performance
**Monthly Orders KPI** – Monitors monthly order trends
***Sales by Payment Mode** – Analysis of different payment methods
***Sales by Year** – Year-wise sales comparison
**Interactive Slicers** – Filter the dashboard by Year and State

##  Tools & Technologies

* **Microsoft Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Measures and calculations
* **Data Modeling** – Relationships between fact and dimension tables
* **Data Visualization** – Interactive charts, KPIs, slicers and tables

##  Data Model

The Power BI model contains multiple tables, including:

* **Sales** – Transaction and payment-related information
* **Products** – Product and category information
* **Customers** – Customer and state information
* **Calendar** – Date, month and year information
* **Measure Table** – DAX measures used for dashboard calculations

The model follows a structured relational approach to enable efficient analysis across different dimensions.

##  Key Business Analysis

The dashboard enables analysis of:

1. Overall sales and order performance
2. Customer base and average order value
3. Product category performance
4. Best-selling products
5. Monthly sales trends
6. Monthly order trends
7. Payment-mode preferences
8. Year-over-year sales performance
9. State-level filtering and analysis
